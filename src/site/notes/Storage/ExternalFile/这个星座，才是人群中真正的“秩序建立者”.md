# 1 这个星座，才是人群中真正的“秩序建立者”

提起天秤座，我们仿佛已经看到了一位“好好先生/女士”，自带优雅的氛围和举止，擅长于维系人际关系，在社交场上游刃有余。又或者，在一些人眼中，天秤座似乎总是带着一层面具。但在丹恩·鲁伊尔这位人本主义占星学之父面前，天秤座象征着一个新的阶段，它从前一位处女座的“自我审视和自我约束”阶段中走出，为天秤座建立“理想群体”的愿景打下了基础，而这一切远远没有到头。欢迎阅读收藏，本文值得反复阅读。

## 1.1 天秤座的道路

沿着黄道十二星座展开的这场象征性旅程，已经带领我们从令人敬畏的狮身人面像前走过，进入由它开启的处女座阶段，接受这一阶段的学习与磨炼。现在，我们面对的是一座神秘的建筑——举世皆知的大金字塔。这座建筑体现了天秤座所代表的宇宙意义，也体现了秋分的意义：夜之力战胜昼之力，逐渐占据主导地位。

在天秤座，狮子座的自我主张与处女座的自我批判，通过将自我奉献给整个人类而得到调和与超越。在这份奉献中，自我依然存在，但它不再充当主宰，也不再扮演批评者或仆从。它更像一枚聚光的透镜，让整体之光在其中汇聚，并通过它发挥作用，促使每个人成为人类这个有机整体的参与者。

所谓参与者，就是一个真正付诸行动的人：他/她自觉地为整体意志的实现而努力，克服个体自我的狭隘局限。

天秤座象征着个体在一个更大整体中的新生。从此，个体将像身体里的一个细胞那样，在整体中发挥自己的作用。秋分标志着，联合行动与社会合作取得了决定性的优势，超越了个人主义式的自我表达，以及以自身感受为中心的状态。

不过，这还不是最终的胜利，正如春分也不意味着人格的建立已经完成。但经过天秤座阶段之后，前方的目标应当逐渐清晰。每一位真诚的探索者，都有机会看见前进的方向，并理解其中的意义。

新的能量正在被唤起，它们来自群体合作与人与人之间的交流。新的视野随之打开，新的目标也逐渐显露出轮廓。围绕自我筑起的堡垒——至少在理论上——已经被打破。原本封闭其中的生命，应当能够与同伴们的生命自由交融。

这些同伴共同分享着奉献的面包，愿意为整体的福祉贡献自己；同时，他们也准备好融入一个具有层级秩序的群体组织。

![Image|600](/img/user/Storage/Img/%E8%BF%99%E4%B8%AA%E6%98%9F%E5%BA%A7%EF%BC%8C%E6%89%8D%E6%98%AF%E4%BA%BA%E7%BE%A4%E4%B8%AD%E7%9C%9F%E6%AD%A3%E7%9A%84%E2%80%9C%E7%A7%A9%E5%BA%8F%E5%BB%BA%E7%AB%8B%E8%80%85%E2%80%9D/image-002.png)

有人说，天秤座善于投机、反复无常，让人难以信赖。但这些都只是表面现象。从心理层面来看，真正的原因是：为了符合群体对自己的期待，天秤座愿意竭尽所能——而这种期待，也可能只是他们自己认为群体对他们有所期待。

这使他们在作决定时显得摇摆不定，难以让人放心。有时，他们看起来就像一只变色龙——机会主义者的象征——随着环境改变自己的颜色，以适应处境，甚至进一步融入所处的情境。

这种“融入情境”的倾向，正是天秤座行为的核心。然而，在这种表现之下，却藏着强烈的个人自尊，以及容易受伤的敏感。有时，他们还会痛苦地觉得，无论是在家庭中，还是在社会生活中，自己都无法充分完成为自己设定的任务。

天秤座与白羊座都处于一种不稳定的平衡之中。 在这两个星座里，昼之力与夜之力几乎势均力敌，因此很容易出现焦躁不安、紧张，甚至神经质的表现。

天秤座在意识层面希望自己能够融入社会、不以个人为中心、追求精神层面的价值，并与共事的人建立丰富而有意义的联系；但在潜意识里，至少在他们自己的感受中，自己似乎总是达不到心中的理想标准，而那个目标也总是难以企及。

因此，他们很容易一阵阵地陷入沮丧，随后又以过度的热情投入社会事务和群体活动。他们始终在寻找理想的群体、理想的合作方式，也把人与人之间的关系看得格外庄重、严肃。

然而，他们对这些关系投入得如此用力，以至于可能因为一心追逐理想，而忽略了眼前的真实情况。他们可能因为太想维护整片森林的完整，反而毁伤了其中的一棵棵树。

不过，当天秤座发挥出最好的一面时，他们是出色的群体活动组织者，善于协调各方、将不同的人和力量凝聚起来。

或许，越是对自身的内在协调缺乏把握，他们就越会努力在群体中促成协调。群体是否和谐、人与人相处是否幸福、关系能否承载共同的理想，对他们来说，都是如同生死一般重要的事。争论与内部纷争会使他们的神经失去平衡，甚至让他们在精神上彻底耗竭。他们还无法像摩羯座那样，在外交上的勾心斗角与政治谋略中游刃有余。

到了摩羯座，社会意识已经稳固下来，就像到了巨蟹座，自我意识已经扎根一样。但在天秤座和白羊座这里，一切都还没有定型：前者所代表的社会、后者所代表的人格，都仍在形成之中。既然一切才刚刚成形，人就很难完全放松、从容应对。因为一旦觉得自己做得不够好，或是退回了过去的态度，他们就会把这看成一场可怕的悲剧。

## 1.2 天秤座的另一个成长阶段

## 1.3 ##

因此，当天秤座成长到能够真正理解社会如何运作的阶段时，就会需要坚定的理想信念来支撑自己。白羊座会寻找一位超人般的人物或大师，希望将自己尚未稳固的人格所带来的、时而难以承受的重担交给对方；同样，天秤座也会寻找一个理想的群体，或一种理想的社会模式，让自己在参与社会生活时感到安全、有所依托。

太阳位于天秤座的甘地，也表现出了这种崇高的社会理想。

另一方面，发展尚不成熟的天秤座，往往会在人与人最容易建立联系的层面展开交往——也就是身体吸引的层面。

还有一些天秤座，则在艺术中找到了发挥才能的领域。天秤座由金星守护，赋予人美丽的容貌与迷人的魅力，也象征着文化修养与精致的审美。凡是通过某种形式，把分散的元素组合成一个有秩序、有美感的整体的地方，都能看到天秤座的力量在发挥作用。

不过，人们往往没有充分理解这里所说的“形式”。任何一种社会组织，包括工业管理，都建立在形式的原则之上：各个部分需要以一定的方式组织起来。只要两个或更多独立的个体之间建立了相对持久的关系，就意味着某种形式或模式已经形成。夜之力在整个黄道中的运作，都依赖于形式。没有形式，分散的部分就无法真正聚合在一起。

每一件艺术作品，都是将原本独立的元素按照一定形式组合、安排起来的结果，无论这些元素是颜料、线条、音调，还是各种物质材料。社会群体也是如此。天秤座是一位构想着理想形式的艺术家，而摩羯座则会让这些理想的形式在人们的现实生活中具体成形，成为可以切实感受到的存在。

![Image|600](/img/user/Storage/Img/%E8%BF%99%E4%B8%AA%E6%98%9F%E5%BA%A7%EF%BC%8C%E6%89%8D%E6%98%AF%E4%BA%BA%E7%BE%A4%E4%B8%AD%E7%9C%9F%E6%AD%A3%E7%9A%84%E2%80%9C%E7%A7%A9%E5%BA%8F%E5%BB%BA%E7%AB%8B%E8%80%85%E2%80%9D/image-004.png)

除了“形式”，还有一个因素在天秤座的行动与反应中格外突出，那就是衡量与评价。这就需要我们重新理解天秤座所对应的天平符号。不能只看这个符号的表面意思，就认定天秤座是“平衡的人”。他们有时确实如此，但在许多重要的事情上，他们也常常走向极端，即使表面上看起来愿意为了维持群体和谐而让步。

天平这个符号，其实有另一层含义。天平是用来称量物品的，而称量，就是把物品的质量与一个社会公认的标准重量作比较。因此，称重本身就是依据社会共同认可的尺度，来测量和评价一件事物的基本属性——它的质量或重量。之所以说质量是一种基本属性，是因为它涉及物体与整个地球的关系，也就是引力关系；此外，各种价值又都以一定数量的黄金为参照来估量。

所以，天平象征着对事物最基本属性的衡量与评价。它强调的重点并不是“平衡”本身——平衡只是实现目的的手段——而是评价、测量，以及在此基础上作出的判断。

从本质上说，天秤座会依据某些既定的社会标准，来评价事物、人物和事件。这些标准可能来自传统，也可能来自理想。他们或许还不够确信自己在社会中的地位，因而没有足够的底气“以社会的名义”作出评判——射手座却会毫无顾忌地这样做。不过，天秤座其实已经权衡过各种依据，并把每件事都放到了自己认为合适的位置上。

是否对社会有用、能否在群体中和谐地发挥作用，是天秤座作出评价时采用的主要标准。这些既是社会标准，也是审美标准。天秤座之所以常常在艺术领域发挥才能，是因为把乐谱上的音符、画面中的明暗安排妥当，终究比把性格各异的人组织成一个稳定的群体，要容易得多。

![Image|600](/img/user/Storage/Img/%E8%BF%99%E4%B8%AA%E6%98%9F%E5%BA%A7%EF%BC%8C%E6%89%8D%E6%98%AF%E4%BA%BA%E7%BE%A4%E4%B8%AD%E7%9C%9F%E6%AD%A3%E7%9A%84%E2%80%9C%E7%A7%A9%E5%BA%8F%E5%BB%BA%E7%AB%8B%E8%80%85%E2%80%9D/image-005.png)

我们需要再次强调，天秤座还没有真正掌握如何驾驭社会的运作。他们刚刚走出处女座所强调的那个关键阶段——自我审视与自我约束。此时，他们或许已经看见了“理想社会”的愿景，看见了“新耶路撒冷”——一座完美的城市，或一个完善的国家。但要真正有能力把一个个活生生的人组织起来，建立这样的国家，还需要经历更多的发展阶段。

因此，天秤座怀抱梦想、衡量事物，追寻并传递着那份最终能够促成新群体、新社会的爱。不过，他们是以艺术家的方式来做这些事，而不是以政治家的方式，即使他们可能是一位出色的管理者。相比实际的建设者，他们更像是看见未来的人，以及促成和谐的人。

从另一个角度来说，天秤座也象征着种子。这是有道理的：一株即将枯死的植物，会把全部生命能量凝聚在种子严密而固定的组织结构中。种子象征着理想的群体或组织，也象征着自我牺牲。因此，天秤座第1度的象征，是一只“被智慧之箭刺穿的蝴蝶”。此前的处女座阶段，则相当于蝶蛹的阶段。处女座从各个方面，为天秤座的到来做好准备。

到了天秤座，“新的生命”开始了：个体开始以参与者的身份，进入社会或某个更大整体的共同生活。天秤座就像一位经历入门仪式的人，从金字塔国王墓室中那具神秘的石棺里起身。他已经看见了愿景，也认清了自己在最亲近的群体乃至整个宇宙中的位置与作用。

现在，展现在他面前的是一条服务于群体的道路。但如果他不能从自身的各个层面，充分体验这个更大整体的真实存在，那么这样的服务也就没有多少价值。因此，到了天蝎座，这个整体的现实必须深入他的感受与情绪，让构成人格内在实质的情感生命重新焕发活力；到了射手座，它还必须进一步转化他的思想。

天秤座所看见的愿景，需要在天蝎座成为切身的生命体验，再在射手座被整理、表达为清晰的思想。而当冬至到来时，圣婴基督诞生了：上帝，或者说人类整体，化身为一个具体的人。
